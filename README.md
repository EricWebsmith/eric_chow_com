# React + TypeScript + Vite starter

This repo contains a minimal website scaffold built with React 19, TypeScript, Vite 8, React Router, i18next, Vitest, and ESLint.

## Stack

- React 19
- TypeScript
- Vite 8
- React Router DOM
- i18next + react-i18next
- Vitest + Testing Library
- ESLint

## Getting started

```bash
npm install
npm run dev
```

## Available scripts

```bash
npm run dev
npm run build
npm run preview
npm test
npm run lint
```
